# Ulyiomy releases

This repository contains the signed APK releases for Ulyiomy, the private manhwa reader.

## Install

Download `Ulyiomy-v<version>.apk` from [Releases](https://github.com/upavloff/ulyiomy-releases/releases), allow APK installation when Android asks, and open the file.

## Update

Ulyiomy checks this repository for newer releases. Accept the in-app update prompt to download and install one. Keep the app installed so Android can verify the existing signing key.
